### <a id="osu_Framework_Graphics_Cursor_IHasContextMenu_ContextMenuItems"></a> ContextMenuItems

Menu items that appear when the drawable is right-clicked.

```csharp
MenuItem[]? ContextMenuItems { get; }
```

#### Property Value

 [MenuItem](osu.Framework.Graphics.UserInterface.MenuItem.md)\[\]?

#### Remarks

If empty, this <xref href="osu.Framework.Graphics.Drawable" data-throw-if-not-resolved="false"></xref> will be picked as the menu target but a context menu will not be shown.
<p>If null, this <xref href="osu.Framework.Graphics.Drawable" data-throw-if-not-resolved="false"></xref> will not be picked as the menu target and other <xref href="osu.Framework.Graphics.Drawable" data-throw-if-not-resolved="false"></xref>s underneath may become the menu target.</p>
