# <a id="osu_Framework_Graphics_Shapes"></a> Namespace osu.Framework.Graphics.Shapes

### Classes

 [Box](osu.Framework.Graphics.Shapes.Box.md)

A simple rectangular box. Can be colored using the <xref href="osu.Framework.Graphics.Drawable.Colour" data-throw-if-not-resolved="false"></xref> property.

 [Circle](osu.Framework.Graphics.Shapes.Circle.md)

A simple <xref href="osu.Framework.Graphics.Containers.CircularContainer" data-throw-if-not-resolved="false"></xref> with a fill using a <xref href="osu.Framework.Graphics.Shapes.Box" data-throw-if-not-resolved="false"></xref>. Can be coloured using the <xref href="osu.Framework.Graphics.Drawable.Colour" data-throw-if-not-resolved="false"></xref> property.

 [EquilateralTriangle](osu.Framework.Graphics.Shapes.EquilateralTriangle.md)

A triangle which has all side lengths and angles equal.

 [FastCircle](osu.Framework.Graphics.Shapes.FastCircle.md)

A circle that is rendered directly to the screen using a specialised shader.
This behaves slightly differently from <xref href="osu.Framework.Graphics.Shapes.Circle" data-throw-if-not-resolved="false"></xref> but offers
higher performance in scenarios where many circles are drawn at once.

 [Triangle](osu.Framework.Graphics.Shapes.Triangle.md)

Represents a sprite that is drawn in a triangle shape, instead of a rectangle shape.
