### <a id="osu_Framework_Tests_Bindables_BindableNumberTest_TestDecimalPrecision"></a> TestDecimalPrecision\(\)

This test exercises that when sitting a decimal <xref href="osu.Framework.Bindables.BindableNumber%601.Precision" data-throw-if-not-resolved="false"></xref> like 0.1 on a <code>BindableNumber&lt;float&gt;</code>,
the resulting <xref href="osu.Framework.Bindables.BindableNumber%601.Value" data-throw-if-not-resolved="false"></xref> is the closest to the actual closest <code>float</code> number
to the real-world decimal.
This matters because certain methods of rounding to the precision specified on the <xref href="osu.Framework.Bindables.BindableNumber%601" data-throw-if-not-resolved="false"></xref>
cause rounding errors that show up elsewhere in undesirable ways.

```csharp
